# Desarrollo Web – Curso 2026-IIA

Repositorio oficial del curso **Desarrollo Web – Sección I.02.2026-IIA (Ate)**.

Este repositorio se utilizará durante el desarrollo del curso para compartir **material de clase, ejemplos prácticos, ejercicios y recursos utilizados en las sesiones**.

---

## 📚 Descripción del curso

En esta unidad didáctica los estudiantes aprenderán a **diseñar y desarrollar sitios web** utilizando:

* HTML
* CSS
* Bootstrap

Al finalizar el curso, los estudiantes estarán capacitados para desarrollar **sitios web funcionales y adaptables (responsive)** siguiendo estándares actuales de la industria.

---

## 🎯 Competencias del curso

Al finalizar la unidad didáctica el estudiante será capaz de:

* Identificar los fundamentos del diseño de un sitio web.
* Aplicar etiquetas HTML para la construcción de páginas web.
* Utilizar estilos CSS para mejorar la presentación y maquetación.
* Implementar el framework **Bootstrap** para construir interfaces adaptables.
* Organizar la estructura básica de un proyecto web.

## 📂 Contenido del repositorio

| Carpeta / Archivo   | Tipo          | Descripción                                                                                                       |
| ------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------- |
| `assets/`           | Carpeta       | Recursos utilizados en los ejemplos del curso como archivos CSS, JavaScript, imágenes y otros recursos estáticos. |
| `examples/`         | Carpeta       | Ejemplos adicionales utilizados para explicar componentes y funcionalidades del desarrollo web.                   |
| `pages/`            | Carpeta       | Páginas web completas utilizadas como demostración durante las clases.                                            |
| `class/`            | Carpeta       | Archivos utilizados durante las sesiones prácticas o demostraciones en clase.                                     |
| `index.html`        | Archivo       | Página principal de ejemplo del proyecto utilizada como punto de entrada.                                         |
| `demo.html`         | Archivo       | Página de demostración con ejemplos aplicados vistos en clase.                                                    |
| `formulario.html`   | Archivo       | Ejemplo de implementación de formularios HTML.                                                                    |
| `.gitignore`        | Configuración | Define qué archivos o carpetas no deben subirse al repositorio.                                                   |
| `package.json`      | Configuración | Archivo que gestiona dependencias del proyecto (por ejemplo Bootstrap Icons).                                     |
| `package-lock.json` | Configuración | Registro automático de las versiones exactas de las dependencias instaladas.                                      |

## 🚀 Cómo usar este repositorio

1. Clonar el repositorio

```bash
git clone <url-del-repositorio>
```

2. Abrir el proyecto en **Visual Studio Code** u otro editor de código.

3. Ejecutar los archivos `.html` directamente en el navegador.

## 💡 Recomendaciones para estudiantes

* Revisar los ejemplos después de cada clase.
* Analizar la estructura del código antes de modificarlo.
* Realizar pruebas cambiando el código para comprender mejor el funcionamiento de HTML, CSS y Bootstrap.
* Utilizar este repositorio como referencia para tareas y ejercicios del curso.
